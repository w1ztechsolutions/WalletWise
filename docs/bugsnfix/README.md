# Bug Reports & Fixes Log

This directory tracks all encountered issues, build/runtime bugs, edge cases, root cause analyses, and solutions implemented during the development and maintenance of **WalletWise**.

---

## Logging Format

When an issue occurs, add an entry below or create an individual markdown file in this directory following this template:

```markdown
### [BUG-XXX] Short Title
- **Date:** YYYY-MM-DD
- **Severity:** Low | Medium | High | Critical
- **Symptoms / Error Message:**
  Description of what failed or the exact error output.
- **Root Cause:**
  Technical explanation of why the failure occurred.
- **Fix Implemented:**
  Code changes or configuration adjustments made.
- **Verification:**
  How the fix was verified.
```
